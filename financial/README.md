# ระบบบริหารการเงินและบัญชีสถานศึกษา (School Financial & Accounting Management System)
### โรงเรียนละลมวิทยา | Lalompittayakhom School

เว็บแอปพลิเคชันบริหารการเงิน บัญชีคู่ งบประมาณ จัดซื้อจัดจ้าง พัสดุครุภัณฑ์ และการกระทบยอดธนาคาร พัฒนาด้วยสถาปัตยกรรม Clean MVC (PHP + MySQL + Bootstrap 5) สำหรับสถานศึกษาภาครัฐ

---

## 1. คุณสมบัติของระบบ (Core Features)

1. **แดชบอร์ดผู้บริหารและการเงิน (Executive & Finance Dashboard)**
   - สรุปงบประมาณที่ได้รับ, ยอดผูกพัน (Commitment), ยอดเบิกจ่ายจริง, และงบคงเหลือสุทธิ
   - ติดตามยอดเงินสดคงเหลือและยอดตามบัญชีธนาคาร (แยกความหมายชัดเจน)
   - กราฟรายรับ-รายจ่ายรายเดือน และโครงการที่ใช้งบประมาณใกล้เต็มเกณฑ์เตือน (Threshold)
2. **ระบบควบคุมงบประมาณอัตโนมัติ (Automated Real-time Budget Control)**
   - คำนวณเปอร์เซ็นต์การใช้วงเงินตามสูตร:
     $$\text{Percent} = \frac{\text{ยอดจ่ายสะสม} + \text{ยอดผูกพัน} + \text{รายการใหม่}}{\text{งบประมาณสุทธิ}} \times 100$$
   - เตือนเมื่อแตะ $80\%$ และบล็อกเด็ดขาดเมื่อถึง $100\%$
   - ล็อกแถวข้อมูล (`SELECT ... FOR UPDATE`) ป้องกันการแย่งยื่นคำขอพร้อมกัน
3. **ระบบรับเงิน (Receipt Management)**
   - เงินอุดหนุนรายหัว, เงินรายได้สถานศึกษา, เงินบริจาค, ค่าบำรุงการศึกษา
   - ออกใบเสร็จรับเงิน, บันทึกเงินสด/เงินโอน, ใบนำฝากธนาคาร โดยไม่ลงรายรับซ้ำ
4. **ระบบเบิกจ่ายเงิน (Disbursement Workflow)**
   - ร่าง $\rightarrow$ เสนอ $\rightarrow$ ตรวจสอบ $\rightarrow$ อนุมัติ $\rightarrow$ จ่ายเงิน $\rightarrow$ บันทึกบัญชี
   - ระบบใบสำคัญจ่าย (Payment Voucher), หักภาษี ณ ที่จ่าย, ป้องกันการกดจ่ายซ้ำ
5. **ระบบเงินยืมราชการและสัญญายืมเงิน (Advance & Clearing Management)**
   - สัญญายืมเงิน (แบบ 8500), กำหนดวันครบกำหนด, ใบส่งใช้เงินยืม
   - จัดการเงินเหลือส่งคืน หรือเบิกจ่ายส่วนต่างเพิ่ม ป้องกันการนับรายจ่ายซ้ำ
6. **ระบบบัญชีคู่ภาครัฐ (Double-Entry Ledger)**
   - ผังบัญชี 5 หมวด (สินทรัพย์, หนี้สิน, ทุน, รายได้, ค่าใช้จ่าย)
   - สมุดรายวันทั่วไป, บัญชีแยกประเภท, งบทดลอง ($\text{Debit} = \text{Credit}$)
   - ข้อมูลบัญชีที่ผ่านการลงรายการแล้วไม่สามารถลบหรือแก้ไขได้โดยตรง (ใช้รายการกลับบัญชี/ปรับปรุง)
7. **บัญชีธนาคารและการกระทบยอด (Bank Reconciliation)**
   - รองรับอย่างน้อย 12 บัญชีธนาคาร
   - นำเข้า Statement (CSV / Excel) พร้อมระบบช่วยจับคู่รายการ (Auto-match candidate)
8. **ห้องเรียนพิเศษและค่าบำรุงการศึกษา (Special Programs & Tuition Fees)**
   - รองรับ EP, MEP, IEP, IP, Gifted, SMP และประเภทที่เพิ่มได้เอง
   - จัดการรายการเรียกเก็บ, ส่วนลด, การผ่อนผัน และยอดค้างชำระ
9. **จัดซื้อจัดจ้าง พัสดุ และครุภัณฑ์ (Procurement & Inventory / Assets)**
   - แผนจัดซื้อจัดจ้าง, ใบขอซื้อ/ขอจ้าง (PR), เปรียบเทียบราคา, ใบสั่งซื้อ/สั่งจ้าง (PO), รายงานตรวจรับ
   - ทะเบียนวัสดุ (Stock In/Out) และทะเบียนครุภัณฑ์พร้อมประวัติซ่อมบำรุง/จำหน่าย
10. **เอกสารและรายงานราชการ 28 แม่แบบ**
    - สร้างเอกสาร PDF สวยงาม ฟอนต์ TH Sarabun New ไม่มีปัญหาตัดคำหรือสี่เหลี่ยม
    - แปลงยอดเงินเป็นภาษาไทย (BahtText) รองรับทศนิยมและหลักล้านอย่างแม่นยำ
11. **ความปลอดภัยและประวัติการใช้งาน (Strict RBAC & Audit Trail)**
    - แยกบทบาท: ผู้ดูแลระบบ, เจ้าหน้าที่การเงิน, เจ้าหน้าที่บัญชี, เจ้าหน้าที่พัสดุ, ผู้ขอเบิก, ผู้ตรวจสอบ, ผู้อนุมัติ, ผู้บริหาร
    - บันทึก Audit Log ทุกเหตุการณ์สำคัญ ป้องกัน CSRF, SQL Injection, Session Hijacking
    - จัดเก็บไฟล์ลายเซ็นและตราประทับนอก Public Directory พร้อมระบบควบคุมสิทธิ์

## 2. ความต้องการของระบบ (System Requirements)

- **PHP**: เวอร์ชัน `8.1` ขึ้นไป (แนะนำ PHP 8.2 หรือ 8.3)
- **PHP Extensions**:
  - `pdo` และ `pdo_mysql`
  - `mbstring` (ประมวลผล UTF-8 ภาษาไทย)
  - `openssl` (การเข้ารหัสความปลอดภัย)
  - `json`
  - `gd` (สำหรับปรับแต่งภาพลายเซ็นและตราประทับ)
  - `fileinfo` (ตรวจสอบ MIME Type ของไฟล์อัปโหลด)
- **Database**: MySQL `5.7+` หรือ `8.0+` / MariaDB `10.3+` (รองรับ InnoDB และ UTF8MB4)
- **Web Server**: Apache (`mod_rewrite` เปิดใช้งาน) หรือ Nginx

## 3. โครงสร้างสารบบไฟล์ (Directory Structure)

```
financial/
├── app/
│   ├── Controllers/               # Controller จัดการ Request
│   ├── Models/                    # Model สำหรับ Entity และ Query
│   ├── Services/                  # Business Logic (Budget, Accounting, BahtText, PDF)
│   ├── Middleware/                # Auth, RBAC, CSRF Filter
│   ├── Helpers/                   # ฟังก์ชันช่วยเหลือ (BahtText, Date, Currency)
│   └── Views/                     # หน้าจอแสดงผล UI (Bootstrap 5)
├── config/                        # การตั้งค่า (Database, App, Permissions)
├── database/                      # Migrations & Seeders
├── storage/                       # ที่จัดเก็บไฟล์นอก Public (Signatures, Seals, Uploads)
├── public/                        # Public Directory (index.php, CSS, JS)
├── composer.json                  # Composer Configuration
├── .env.example                   # ตัวอย่าง Environment Variables
└── README.md                      # เอกสารนี้
```

## 4. วิธีการติดตั้ง (Installation Guide)

### 4.1 คัดลอก Environment Configuration
```bash
cp .env.example .env
```
กำหนดค่าฐานข้อมูล (`DB_HOST`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`) และข้อมูลหน่วยงานในไฟล์ `.env`

### 4.2 ติดตั้ง Composer Dependencies
```bash
composer install --no-dev --optimize-autoloader
```

### 4.3 สร้างฐานข้อมูลและรัน Migration
```bash
php database/migrate.php
```

### 4.4 กำหนดสิทธิ์โฟลเดอร์ Storage
```bash
chmod -R 775 storage
```

## 5. แผนการส่งมอบงาน (Delivery Phases)

- **ระยะที่ 1 (เสร็จสมบูรณ์)**: สรุปความต้องการ ผังระบบ ER Diagram โครงสร้างไฟล์ และขั้นตอนอนุมัติ
- **ระยะที่ 2**: ระบบติดตั้ง เข้าสู่ระบบ สิทธิ์ผู้ใช้ ตั้งค่าหน่วยงาน ปีงบประมาณ และ Audit Log
- **ระยะที่ 3**: งบประมาณ รับเงิน จ่ายเงิน เงินยืม และบัญชีคู่ ให้เชื่อมกันใช้งานได้ครบหนึ่งกระบวนการ
- **ระยะที่ 4**: ธนาคาร กระทบยอด และค่าบำรุงการศึกษา
- **ระยะที่ 5**: จัดซื้อจัดจ้าง พัสดุ ครุภัณฑ์ เอกสาร และรายงาน
- **ระยะที่ 6**: ทดสอบความถูกต้อง ความปลอดภัย และจัดทำคู่มือ
